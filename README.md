# ממיר אודיו

ממיר קבצי אודיו ל-MP3 או WAV שרץ כולו בדפדפן. הקבצים לא עולים לשום שרת.

- קלט: MP3, WAV, M4A/AAC, OGG/Opus, FLAC ופס הקול מקובצי וידאו (מה שהדפדפן יודע לפענח)
- פלט: MP3 (128–320 kbps) או WAV (16/24-bit)
- קצב דגימה 22.05–48 kHz, מונו או סטריאו
- עובד גם בלי אינטרנט אחרי הביקור הראשון, ואפשר להתקין על מסך הבית

## העלאה ל-GitHub Pages

1. צור מאגר חדש ב-GitHub (למשל `audio-converter`), ציבורי.
2. העלה את כל הקבצים מהתיקייה הזו לשורש המאגר (Add file → Upload files).
3. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, תיקייה **/ (root)** → Save.
4. אחרי דקה-שתיים האפליקציה זמינה בכתובת `https://<שם-המשתמש>.github.io/audio-converter/`.

## התקנה בטלפון

- **אייפון (Safari):** כפתור שיתוף → "הוסף למסך הבית".
- **אנדרואיד (Chrome):** תפריט ⋮ → "התקן אפליקציה" או "הוסף למסך הבית".

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה עצמה |
| `manifest.webmanifest` | שם, צבעים ואייקונים להתקנה |
| `sw.js` | שמירה במטמון לשימוש בלי אינטרנט |
| `icon*.png`, `icon.svg` | אייקונים |

מקודד ה-MP3 הוא [lamejs](https://github.com/zhuker/lamejs) (רישיון LGPL), נטען מ-jsDelivr.
