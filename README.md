# ממיר מדיה

מכווץ וידאו לוואטסאפ וממיר אודיו ל-MP3 או WAV. הכול רץ בדפדפן, והקבצים לא עולים לשום שרת.

**וידאו:** הגדרות מוכנות (וואטסאפ בלי טשטוש 540p, וואטסאפ HD 720p, אייפון 1080p, קל במיוחד 480p, לפי גודל קובץ) וכוונון ידני של רזולוציה, ביט רייט, פריימים ושמע. המרת HDR של אייפון ל-SDR. פלט MP4 (H.264 High Profile). דורש Chrome מעודכן או Safari 17 ומעלה.

**אודיו:**

- קלט: MP3, WAV, M4A/AAC, OGG/Opus, FLAC, וחילוץ שמע מסרטונים
- פלט: MP3 (128–320 kbps) או WAV (16/24-bit)
- קצב דגימה 22.05–48 kHz, מונו, סטריאו או פיצול ל-2 קובצי מונו (L/R)
- ברירת מחדל: MP3 320 kbps, WAV 16-bit 48 kHz (מתאים לנגן ה-USB של X32)
- עובד גם בלי אינטרנט אחרי הביקור הראשון, ואפשר להתקין על מסך הבית

## העלאה ל-GitHub Pages

1. צור מאגר חדש ב-GitHub (למשל `audio-converter`), ציבורי.
2. העלה את כל הקבצים מהתיקייה הזו לשורש המאגר (Add file → Upload files).
3. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, תיקייה **/ (root)** → Save.
4. אחרי דקה-שתיים האפליקציה זמינה בכתובת `https://<שם-המשתמש>.github.io/audio-converter/`.

## התקנה בטלפון

- **אייפון (Safari):** כפתור שיתוף → "הוסף למסך הבית".
- **אנדרואיד (Chrome):** תפריט ⋮ → "התקן אפליקציה" או "הוסף למסך הבית".

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה עצמה |
| `manifest.webmanifest` | שם, צבעים ואייקונים להתקנה |
| `sw.js` | שמירה במטמון לשימוש בלי אינטרנט |
| `icon*.png`, `icon.svg` | אייקונים |

קידוד הווידאו נעשה עם [Mediabunny](https://github.com/Vanilagy/mediabunny) (רישיון MPL-2.0), וה-MP3 עם [lamejs](https://github.com/zhuker/lamejs) (רישיון LGPL). שניהם נטענים מ-jsDelivr.
